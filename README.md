# AI workshop workbook

An interactive workbook for a half-day leadership workshop on AI. Plain static HTML, CSS and JS with no build step.

- Open `index.html` to start.
- Everything participants type stays in their own browser (localStorage). Nothing is sent anywhere.
- Works offline: download or unzip the folder and open `index.html`.
- **Tested in Chrome only.** Other browsers may work but aren't guaranteed. Opened from a local folder, some browsers (e.g. Firefox) may not carry notes between pages.
- Printable support-desk materials: `support-desk-printables.pdf`.
