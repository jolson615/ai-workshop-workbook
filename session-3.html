Deconstructing a proposed agent

“I wish I could wake up and an agent would have prepared a daily digest that tells me exactly where to point my focus that day.”

  1. wake up and … prepared→Automation
  2. a daily digest→Context
  3. exactly→Refinement
  4. where to point my focus→Judgment

This starts from a solution. Start from the problem.

Step 2: check it

–

Check it against the three tests.

  1. Has a number

    Does it include a number, or something you could measure?

  2. No “AI”

    Does it avoid the word “AI”?

  3. No “should”

    Does it avoid judgment words like “should”?

For comparison: “My team should be using AI more.” fails all three.

Why these three checks

  • Has a number

    Without a number, you can’t tell if you’re making progress.

  • No “AI”

    If AI is in the problem, it can’t also be the solution.

  • No “should”

    “Should” is a judgment, not a problem.

What good statements look like

  • BeforeOur recruiters should1 use AI2 to keep up with3 candidates.

    1. 1judgment word
    2. 2solution, not problem
    3. 3vague

    AfterOur recruiters spend an average of 10 hours a daya number on candidate messages.

  • BeforeLegal needs AI1 to get through tickets faster2.

    1. 1solution, not problem
    2. 2vague

    AfterThe legal ticket backlog is growing faster than we can clear itmeasurable.

  • BeforeThe policy team should1 be more responsive2 to executives.

    1. 1judgment word
    2. 2vague

    AfterOur executives need briefs faster than the policy team can write them at the quality we needquality bar.

  • BeforeWe should1 launch an AI chatbot2 for customer service.

    1. 1judgment word
    2. 2solution, not problem

    After30% of customersa number wait more than 48 hoursmeasurable for an answer.

Step 3: rewrite it

–

Rewrite it so it passes all three tests.

  1. Has a number

  2. No “AI”

  3. No “should”

Example: three things to try

  1. Simplest that could work 1

    Auto-reply with a link to a candidate FAQ, and allow candidates to mark their own request as resolved.

    No AI
  2. 2

    A model drafts each reply, and a second check decides whether a recruiter needs to review it before it’s sent.

    Model + review check
  3. 3

    An agent answers scheduling and status questions on its own, and routes the rest to a recruiter.

    Agent + routing

Start here, then measure the 10 hours again in a month.
