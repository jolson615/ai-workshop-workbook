What is an agent?

A model that decides its own next step, uses tools, and repeats until the job is done.

Adapted from published definitions: source 1 · source 2

A model only ever writes text.

Text can be code.

The harness is the software that runs that code.

Same input, same output?

Deterministic

  1. Input: 1,240 × 12→Output 1: 14,880
  2. Input: 1,240 × 12→Output 2: 14,880
  3. Input: 1,240 × 12→Output 3: 14,880

Same every time: a good task for harness code.

Probabilistic

  1. Input: Summarize yesterday’s board meeting in one sentence.→Output 1: The board approved a price increase and paused hiring until the next review.
  2. Input: Summarize yesterday’s board meeting in one sentence.→Output 2: Directors backed higher prices next quarter and held off on new hires.
  3. Input: Summarize yesterday’s board meeting in one sentence.→Output 3: Yesterday the board agreed to raise prices and freeze hiring for now.

Different each time, by design: a good task for an LLM.

LLM or harness code?

For each task, would you hand it to the model, or to ordinary code that the harness runs?

    Write an apology email

    Reasonable. Here’s why it leans the other way.Tone, context, judgment. This is what language models are for.

    Rename these 400 files to lowercase

    Reasonable. Here’s why it leans the other way.One rule, 400 times. Code does it instantly and never drifts.

    Pick the kinder of these two sentences

    Reasonable. Here’s why it leans the other way.There’s no formula for kind.

    Add up the Q3 column

    Reasonable. Here’s why it leans the other way.A model will usually get it right. A formula always does.

    Count the Rs in “strawberry”

    Reasonable. Here’s why it leans the other way.Models read text in chunks, not letters. One line of code counts perfectly.

    Check if this link works

    Reasonable. Here’s why it leans the other way.The model can’t visit the link. It can ask the harness to check. That request is a tool call.
